# CP5 — Validation và dry run

## Validation

- Dùng task và bảng tại `validation/plan.md`.
- ≥5 người ngoài nhóm; ≥2 người thuộc willing users CP1.
- Không hướng dẫn khi user thao tác.
- Giữ quote nguyên văn và tên/vai.
- Chọn 1–2 thay đổi từ pattern lặp; cập nhật `spec.md` §9.

## Dry run

- [ ] Slide 1: user/job + số evidence.
- [ ] Slide 2: bảng impact 3 ứng viên.
- [ ] Slide 3: demo happy path và case không có nguồn.
- [ ] Slide 4: % golden set so với bar.
- [ ] Slide 5: ≥2 quote validation + thay đổi.
- [ ] Slide 6: 2–3 ưu tiên nếu có thêm một tuần.
- [ ] Demo ≤5 phút; mỗi thành viên nói ≥1 phần.
- [ ] Có screenshot/video backup.
- [ ] Cả 5 người giải thích được phần có tên mình.

Không đánh dấu validation hoàn tất khi chưa có người dùng thật.
